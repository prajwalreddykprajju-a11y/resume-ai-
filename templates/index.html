About ResumeReady.AI

ResumeReady.AI was engineered as a comprehensive college capstone project to address the growing gap between student academic preparation and industry recruitment standards.

Unlike opaque commercial ATS platforms, ResumeReady.AI provides 100% explainable scoring algorithms, explicit year-wise B.Tech CGPA tracking, real document parsing via PyMuPDF and python-docx, and persistent database storage.

Technology Stack Overview
  • Frontend: HTML5, CSS3, Bootstrap 5, JavaScript, Chart.js
  • Backend: Python & Flask Web Server
  • Parsing: PyMuPDF (fitz) & python-docx
  • NLP & Scoring: scikit-learn TF-IDF & Cosine Similarity
  • Database: SQLite Relational Storage
  • PDF Export: ReportLab Document Engine
